<cosmic-sunburst> Web Component

Universal Sunburst Animation

Drop into any web page, React, Vue, Next.js, or HTML template with a single line of code.

How Anyone Can Integrate This Into Their Website

<!-- 1. Include the script (host it on CDN or your own server) -->
<script src="https://princesingh04.github.io/task/sunburst.js"></script>

<!-- 2. Use the component anywhere in HTML -->
<cosmic-sunburst
  theme="sunrise"
  speed="920"
  radius="88"
  rays="180">
</cosmic-sunburst>
